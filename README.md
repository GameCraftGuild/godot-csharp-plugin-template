- Install the
  [*PLUGIN_NAME*](https://godotengine.org/asset-library/asset/ASSETLIB_ID)

- In the editor, open **Project > Project Settings**, go to **Plugins**

[download a ZIP archive](https://github.com/USER/REPOSITORY/archive/master.zip)
